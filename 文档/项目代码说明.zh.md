# 项目代码说明

[English](项目代码说明.md) | 中文

## 概要

`dsh`（DeepSeek Harness）是构建在 Cordis 之上的 agent harness：插件向共享上下文贡献服务、类型化事件与可撤销的副作用，而每一项产品能力——模型适配器、工具注册表、会话日志、乃至 agent loop 本身——都是可以从配置替换的插件。不存在需要打补丁的特权内核。

本页是阅读代码树的地图：说明每个目录负责什么、归档如何构建、以及从哪里开始。

## 顶层结构

| 目录 | 负责 |

| [`python/`](../代码文件/python/README.md) | Python SDK 及其运行时 wheel；它投影的是与 TypeScript SDK 同一条 agent loop |
| [`native/`](../代码文件/native) | `@deepseek-ai/node-addon-system` 源码 |
| `docs/` | 当前状态的仓库文档，双语，发布到文档站点 |
| `scripts/` | 闸门、生成器与构建编排 |
| `benchmarks/` | 性能闸门 |
| `website/` | `docs/` 的 VitePress 投影 |

| `文档/` | 脱离代码即可阅读的产品设计文档（[索引](README.zh.md)） |

## 包分组

包位于 `packages/<group>/<package>/`。按包数量计，规模最大的分组：

| 分组 | 包数 | 角色 |
|---|---|---|
| `client/` | 72 | Web UI 插件：primitives、对话、记忆、子代理、设置等 |
| `experimental/` | 63 | 已评估但未承诺产品支持的能力；实验状态与是否交付无关 |
| `util/` | 23 | 零依赖工具 |
| `session/` | 22 | 只增不改的事件日志、持久化、格式版本、检查点与查询 |
| `shell/`、`core/`、`api/` | 各 10 | 命令执行；产品 API 主干（agent、loop、session、prompt、tools）；远程 BFF 与 RPC 网关 |
| `subagent/`、`llm/`、`host/` | 各 9 | 被委托的 agent；模型 provider；GUI host |
| `fs/`、`test-support/` | 各 8 | 文件系统接缝与工具；测试基础设施 |
| `memory/` | 5 | 长期记忆接缝、其 MemoryBear provider、自动保存、面向模型的工具、以及会话内的 agent 创建 |
| `bundle/` | 6 | 分发层：`base`、`web-app`、`headless`、`sdk-app`、`sdk-minimal`、`acp-app` |

每个包只属于一个分组；分组 README 是该能力族的权威包地图。

## 一个运行中的进程如何装配

一个运行中的 `dsh` 是启动时由有序层合成出来的插件树：**profile**（存在 Harness home 里的具名组合）列出它堆叠的 bundle；每个 **bundle** 携带 Cordis 配置行；然后是用户的 `cordis.patch.yml`，最后是 `--patch` 覆盖层。补丁按 id 定位某一行，整段替换其配置，或插入新行。

```sh
dsh --profile web --dump-config   # 打印本机启动的插件树
```

出厂 profile 有 `web`、`headless`、`sdk`、`sdk-minimal`、`acp`。只有具名 profile 能启动受支持的 Node 应用；包 bin 与临时的进程内挂载会被 `verify-application-entrypoints` 拒绝。

## 一段话概括核心

**Session** 是类型化事件构成的只增不改日志，也是唯一的真相来源：任何进入模型请求的内容都必须能从日志重建，这就是 `model-visible ⟺ logged` 规则。**agent loop** 认领输入、快照模型选择、组装提示段落与工具 schema、流式发出请求、执行工具、关闭回合。每个**能力接缝**——记忆、文件系统、shell、LLM、沙箱、知识——都有三种角色：Service Definition、一个或多个 provider、以及消费者。注册即副作用，插件卸载时会撤回。

## 在代码树里工作

| 需要什么 | 命令 |
|---|---|
| 安装 | `pnpm install`（pnpm workspaces，Node ≥ 24.9） |
| 构建产物 | `pnpm run build:artifacts` |
| 类型检查聚合程序 | `pnpm run build:check` |
| 单元测试 | `pnpm run test` |
| 覆盖率闸门 | `pnpm run test:coverage`（`packages/*/*/src` 逐文件 100%） |
| 文档闸门 | `pnpm run doc-sync` |
| 从源码运行 | `pnpm dsh --profile web`（需要 `DEEPSEEK_API_KEY`） |

改 `packages/` 之前先读 [`AGENTS.md`](../代码文件/AGENTS.md)，完整架构见 [`docs/architecture.md`](../代码文件/docs/architecture.md)。
