# 共享记忆集合

[English](guide.md) | 中文

## 变更

Web 和桌面不再依赖所选模式加载记忆。会话开关跨回合和模式切换持续生效。自动召回读取全局和当前工作区；模型主动写入仅面向当前工作区。旧记录保留在原集合。

## 迁移

1. 使用内置共享服务时，移除配置中重复的根级 MemoryBear 服务。通过 profile 补丁配置 `memory-bear` 项。
2. 保持 `MEMORY_USER` 稳定。工作区集合使用持久化工作区 UUID，迁移 home 目录时保留工作区存储。
3. 显式迁移前先检查旧集合。系统不会自动复制或提升为全局记忆。
4. 在侧边栏打开全局记忆和工作区记忆，确认会话开关刷新后保持。MemoryBear 的终端用户容量必须足够容纳账号的全局和各工作区集合。
5. 在已验证的 Messages 模型上启用主动记忆时，为该模型目录项设置 `memoryProtocol: framed-json-v1`。Harness 校验完整记忆帧，这不表示供应商提供原生记忆 API。显式共享的全局偏好通过集合页面保存。记忆库筛选仅作用于当前页。

共享 GUI 配置默认关闭整轮自动写入；开启记忆时自动召回仍生效，保存由模型主动调用或用户手动操作完成。不支持主动协议的模型需要手动保存。需要保留整轮批量写入的部署可显式设置 `memory-autosave.writeOnTurnEnd: true`。
